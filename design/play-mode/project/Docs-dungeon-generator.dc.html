Overview

Easy Dungeon Generator

Documentation for v1.1.0 Unity 6000.5.0+ Built-in · URP · HDRP namespace DungeonGen

Easy Dungeon Generator is a Unity toolkit for dungeons built from rooms you paint yourself. You design each room in the editor, describe how the dungeon is structured, and DungeonManager places and connects the rooms at runtime. For endless worlds, ChunkDungeonStreamer builds the dungeon around the player as they move.

Authoring and assembly

The package separates what you create from what the generator builds. You paint rooms and set up themes; the generator chooses, places, and connects the room prefabs.

LayerWhat you work withWhat it does

AssemblyDungeonManager, ChunkDungeonStreamerPlan the layout, instantiate the rooms, wire the doors, and decorate and post-process the result.

Features

Room DesignerPaint multi-floor rooms with floors, doors, stairs, and holes, then save them as prefabs. Templates and generationDescribe the structure as a node tree and generate exact or seeded random layouts. Decoration and themesBuild themes from modular prefabs and fill rooms with rule-based decoration. Chunk streamingStream an endless dungeon around a moving player. Culling and NavMeshHide rooms behind closed doors and bake one NavMesh for the whole dungeon. Demo scenesFour ready-to-play scenes with sample content. They need a free art pack.

How generation works

A DungeonManager run validates the template, measures the room prefabs and their doors, plans the layout, and only then replaces the previous dungeon. The steps are:

  1. Validate the template and the room pool.
  2. Plan the layout. The managed planner is the default; the optional Burst planner is a separate implementation.
  3. Instantiate the rooms, wire the matching doors, and place progression items.
  4. Decorate rooms, then run the post-processors such as culling and NavMesh.

If planning fails, the previous dungeon stays in the scene. Set the same fixed seed to reproduce a layout. The planner may retry with a derived seed when rooms do not fit, and the requested seed still gives the same result.

Two modes decide how the template is used. TemplateExact (default) builds every template node as one room. TemplateSequencedRandom treats template nodes as milestones and adds filler rooms and random branches. See Generation modes.

Wall Mode decides how neighboring walls meet at a seam. SingleOnly (default) keeps every room's own walls. DoubleOnly and AllowBoth share one wall for double-sided kits. Details are in Wall mode for double-sided kits.
