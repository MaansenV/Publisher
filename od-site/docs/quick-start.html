Getting started

Quick Start

Documentation for v1.6.0HumanoidURPUnity 6000.5+

Get a playable first-person character in a few minutes. Start with the demo prefabs to see the controller work, then set up your own Humanoid model with the Setup Wizard. Each step links to the guide with the details.

Requirements#

A URP project on Unity 6000.5 (Unity 6.5) or newer, and a Humanoid character model for your own character. The full list is in the Overview.

Fastest start: demo prefabs#

  1. Import the asset (see Import).
  2. In a scene with a floor that has a collider, drag Assets/FBSystem/Demo/Prefabs/FBSystem_CameraRig.prefab into the scene. Delete any other Main Camera.
  3. Drag Assets/FBSystem/Demo/Prefabs/FBSystem_Player.prefab onto the floor.
  4. Press Play. Move with W A S D, look with the mouse, and press 1 to take out the flashlight.

The demo scenes walk you through the controller station by station. See Demos.

Import the asset#

  1. Import Easy FP Full Body Controller from the Asset Store (opens in a new tab) into your URP project. The package installs to Assets/FBSystem/.
  2. Install the Input System and Cinemachine 3 packages if they are not in the project yet.
  3. In Project Settings › Player › Other Settings, set Active Input Handling to Input System Package or Both.

Prepare a Humanoid model#

  1. Select your character FBX in the Project window.
  2. In the Inspector, set Rig › Animation Type to Humanoid, then click Apply.

The Setup Wizard checks this and does not continue without a Humanoid avatar.

Set up your own character#

Open Tools › FBSystem › Setup Wizard and work through the seven steps. The wizard checks each step before you can continue. The guide Setup Wizard explains what each step creates.

  1. Select Player Root: the object that moves the player.
  2. Assign Model: your Humanoid Animator, the input actions and the player settings.
  3. Find Bones: the head, spine and right hand are detected automatically.
  4. Add Player Scripts: adds the controller and IK components.
  5. Setup Helper Objects: the camera target, the elbow hints and the item container.
  6. Connect Everything: wires all references.
  7. Final Health Check: fix all errors, then finish.

Cut the mesh with FPCutter#

To hide the head in first person while keeping its shadow, run the FPCutter Wizard (Tools › FBSystem › FPCutter Wizard) on your character root. It splits the meshes into body parts and generates a copy of the character that hides the head. The guide is FPCutter.

Input#

The asset ships FBInputActions with a Player action map, and PlayerInputHandler reads it. Bindings are in the Input Actions editor. The Setup Wizard links the asset for you. The actions that the code reads are:

  • Move, Look, Sprint, Jump and Crouch (toggle) drive the locomotion and camera.
  • Flashlight (F) uses the held item.
  • Interact (E) sets InteractTriggered. The demo pickup reads the key directly.

Item switching reads the number keys, Q and the mouse wheel directly in ItemSwitcher. See Items.

Press Play#

Enter Play Mode. You should see your own full body in first person, with working movement, look and a held item. To see every event as it happens, add the demo PlayerEventLogger to the player. It logs item and locomotion events to the Console. The event reference is in Interfaces.

Multiplayer (optional)#

For networked play, install the networking library first and then the matching add-on. For FishNet, use FishNet 4.7.2 and the FBSystemFishNet add-on. For PurrNet, use PurrNet v1.22.0 and the FBSystemPurrNet add-on, which supports 2 to 4 players. Each add-on has its own Setup Wizard. See FishNet and PurrNet.

Upgrading#

Upgrading from 1.3

Version 1.6 renamed the foot component and resets the foot settings, and add-ons must be re-imported. Read the steps in Upgrading from 1.3 before you update.
