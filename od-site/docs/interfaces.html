Interfaces

PlayerController#

The hub on the player root. In Awake it fills in any subsystem reference you left empty, so external code needs one reference.

PropertyTypeSubsystem

InputPlayerInputHandlerinput state
LocomotionPlayerLocomotionmovement and physics

HeadIK, HandIK, SpineStabilizerPlayerHeadIK, PlayerHandIK, PlayerSpineStabilizerhead, hand and spine IK
FootPlantingPlayerFootPlantingground-anchored feet
HandItemSocketHandItemSocketitem equip and unequip

Control methods#

Use these for menus, cutscenes and pausing.

MethodNotes
SetInputEnabled(bool)Disabling also clears held input.
SetMovementEnabled(bool), SetCameraEnabled(bool)Toggle locomotion and the camera.

// ...
player.EnableAllControls();    // resume gameplay

PlayerSettings#

A ScriptableObject, created with Create › Player › Settings. Most components read their values from it, so it is the single place to tune the feel. When an asset is assigned, its values override the fields on the components. beginnerMode switches the Inspector to a simplified view.

walkSpeed float default 3
Walking speed in units per second.
sprintSpeed float default 6
Sprinting speed in units per second.
crouchSpeed float default 1.5
Speed while crouching.
crouchHeight, standHeight float default 1 and 2
Height of the CharacterController while crouching and standing.
crouchTransitionSpeed float default 8
Speed of the crouch and stand transition.
jumpHeight float default 1.2
Jump height in units.
gravity float default −15
Gravity. Keep it negative.
groundCheckDistance float default 0.2
Distance below the player that counts as ground.
groundedVelocityReset float default −2
Vertical velocity applied while grounded, to keep the player on slopes and stairs.
inputDeadzone float default 0.01
Smallest input magnitude that counts as movement.
animationSmoothTime float default 0.1
Smoothing of the animator's float parameters.
sprintAnimMultiplier float default 1.5
Animation speed multiplier while sprinting.
defaultHeadHeight float default 1.6
Head height when no head bone is assigned.
lookTargetDistance float default 2
Distance of the look target in front of the player.
cameraFallbackHeadHeight float default 1.7
Camera height when the head bone is not assigned.
verticalLookLimit float default 80
Maximum vertical look angle in degrees.
handVerticalLimitUpper, handVerticalLimitLower float default 45
Look angle, up and down, beyond which the hand IK stops following the view.
enableSpineStabilization bool default true
Turns spine stabilization on or off.
spineStiffness, spineDamping float default 1 and 10
Strength and smoothing of the spine correction.
lowerSpineWeight, middleSpineWeight, upperSpineWeight float default 0.3, 0.3, 0.4
Share of each spine segment in the correction.

PlayerInputHandler#

Reads the FBInputActions asset, using the action map named by actionMapName (default Player).

Per-frame state#

MemberTypeNotes
MoveInputVector2X is strafe, Y is forward, from −1 to 1
LookInputVector2X is horizontal, Y is vertical
IsSprintingboolsprint is held
IsCrouchingbooltoggled on each press of Crouch
JumpTriggeredbooltrue for the single frame of the press
FlashlightTriggeredbooltrue for the single frame of the press (uses the held item)
InteractTriggeredbooltrue for the single frame the Interact action is pressed

Methods#

LockCursor() hides and locks the cursor for gameplay. UnlockCursor() frees it for UI.

The shipped Player map defines Move, Look, Sprint, Jump, Crouch, Flashlight, Interact, Attack, Previous and Next. Previous, Next and Attack are not read by the shipped code.

PlayerLocomotion#

Requires a CharacterController. It fires the locomotion events listed under Event API.

Configurable fields#

Speeds, heights and gravity mirror the values in PlayerSettings. When a settings asset is assigned, the asset wins. Other fields:

groundLayers LayerMask default all layers
Layers that count as ground.

MemberTypeNotes

IsCrouchingbooltrue in the crouch state

PlayerCameraController#

Drives a Cinemachine camera. The camera target follows the head bone and does not inherit the head's animation sway.

crouchEyeOffset Vector3 default (0, 0.05, 0.05)
Offset from the head bone while crouching.
lookSensitivity float default 0.1
Look sensitivity multiplier.
verticalLookLimit float default 80
Maximum vertical look angle in degrees, used when no settings asset is assigned.

Items#

How items are set up and used is explained in Items. This section lists the API.

The single owner of equip and unequip events. A switch plays the holster animation: the current item is lowered out of view, then the new one is raised.

StowingItemGameObjectthe old item still being lowered during a switch
PendingItemGameObjectthe new item waiting to be drawn
IsTransitioningbooltrue while a switch is in progress
Socket, LocomotionTransform, PlayerLocomotionthe socket transform, and the locomotion used for crouch offsets
MethodSignatureNotes
AttachItemAttachItem(GameObject, Vector3? positionOffset = null, Vector3? rotationOffset = null) or AttachItem(GameObject, ItemAttachmentData)attaches an item to the socket
DetachItemGameObject DetachItem(bool destroy = false)detaches the current item
EquipFromContainerEquipFromContainer(GameObject item, int slotIndex = -1)equips an item from a container and applies its ItemHoldData
UnequipToContainerUnequipToContainer() or UnequipToContainer(bool hideImmediately)returns the item to its container. The parameterless overload is kept for existing UnityEvent wiring.
HideStowingItem, CompleteTransitionImmediatelyvoidhide the item being lowered, or finish a running switch at once
UseCurrentItemvoidfires OnUse on the equipped item. It is ignored until the new item is drawn.
RegisterListener, UnregisterListenerIItemEventListeneradd or remove an item listener at runtime

Inspector fields on HandItemSocket: Smooth Transitions (smoothTransitions, default on; off gives the previous instant switch) and Stow Timeout (stowTimeout, default 1 second).

ItemAttachmentData#

The hold, grip and IK data of an item. Its fields are listed in Items: Grips and IK. The key members are holdStyle (OneHandedRight or TwoHanded), gripPositionOffset, gripRotationOffset, the override… switches with their hand and elbow offsets, fingerPoseRight and fingerPoseLeft, and the vertical limits.

ItemIKPreset#

A ScriptableObject, created with Create › Player › Item IK Preset. It stores an ItemAttachmentData in its data field.

Event API#

Every equip, unequip, locomotion change, footstep and vitals change is announced once, in three ways:

MechanismFor
C# eventcode subscribers. Struct payloads avoid allocations per call.
UnityEventInspector wiring without code
Listener interfacesstructured extension. Any component in the player hierarchy that implements one is found at startup.

Payloads#

ItemEquipArgs
Item (GameObject), SlotIndex (int, −1 if the item did not come from a container), HoldData (ItemHoldData), FromContainer (bool).
LandArgs
ImpactVelocity (float, negative when falling), FallDistance (float).
FootStepArgs
IsLeft (bool), Point (Vector3, world position), IsReStep (bool, true for a procedural re-step).

Item events: HandItemSocket#

C# eventTypeUnityEvent
ItemEquippedAction<ItemEquipArgs>OnItemEquipped (ItemEvent)
ItemUnequippedAction<ItemEquipArgs>OnItemUnequipped (ItemEvent)

With smooth transitions, ItemUnequipped fires while the old item is still visible. ItemEquipped can fire for an item that is still waiting to be drawn.

CrouchStarted, CrouchEndedActionOnCrouchStarted, OnCrouchEnded
SprintStarted, SprintEndedActionOnSprintStarted, OnSprintEnded
GroundedChangedAction<bool>OnGroundedChanged

Footstep and vitals events#

SourceC# eventUnityEvent

Listener interfaces#

Implement only the methods you need. The others are no-ops. Use RegisterListener for objects that are added at runtime.

  • IItemEventListener: OnItemEquipped(ItemEquipArgs), OnItemUnequipped(ItemEquipArgs)
  • ILocomotionEventListener: OnJumped(), OnLanded(LandArgs), OnCrouchStarted(), OnCrouchEnded(), OnSprintStarted(), OnSprintEnded(), OnGroundedChanged(bool)
using Player;
using UnityEngine;

public class MyListener : MonoBehaviour, IItemEventListener, ILocomotionEventListener
{
    public void OnItemEquipped(ItemEquipArgs args) => Debug.Log($"equipped {args.Item.name}");
    public void OnLanded(LandArgs args) => Debug.Log($"landed at {args.ImpactVelocity} m/s");
}
MethodNotes
locomotion.RegisterListener(ILocomotionEventListener)adds a locomotion listener at runtime
socket.RegisterListener(IItemEventListener)adds an item listener at runtime
UnregisterListener(...)removes a listener from either source

Subscribe in code#

player.Locomotion.Jumped += () => Debug.Log("jumped");
player.HandItemSocket.ItemEquipped += args =>
    Debug.Log($"equipped {args.Item.name} from slot {args.SlotIndex}");
Delivery

Each transition fires its C# event, its UnityEvent and each listener once, from one place in the code. A listener that throws stops the remaining handlers for that transition, so keep handlers free of exceptions.

Feet, hands, head and vitals#

The Setup Wizard configures these components. Change them directly only for custom behaviour. The tuning of each is in its guide: Body IK and Vitals.

PlayerFootPlanting#

On the model. Runs at execution order -200, before the camera syncs to the head.

MemberSignature or typeNotes
SetEnabledSetEnabled(bool)turns planting on or off at runtime
ResetPlantingResetPlanting()resets the anchors. Call it after a teleport.
SetExternalDriveState, ClearExternalDriveStateSetExternalDriveState(bool grounded, Vector2 moveDirection)drives a remote player from a network add-on. The PurrNet bridge uses it.
ReStepLandedevent Action<FootStepArgs>fires when a re-step lands
PlantModeenumIdle, Moving, Automatic
StepSettingsnested classre-step duration, path, arc, lift, rotation and catch-up curves

PlayerFootsteps#

On the root. Detects steps from the animated feet, without animation events. It raises FootPlanted and OnFootPlanted, listed under Event API.

HandPoseController and FingerPose#

HandPoseController sits on the model and poses the fingers around the held item. It calibrates from the Humanoid muscle limits.

MemberSignatureNotes
CalibrateFromAvatarbool CalibrateFromAvatar()re-reads the finger limits from the avatar.
RebindRebind()rebinds the finger bones
RecaptureReferenceRecaptureReference()captures the reference pose
SnapSnap()applies the current target at once, for example when an item is equipped at start
ResolvedBoneCountint (property)number of finger bones found

FingerPose is a ScriptableObject created with Create › Player › Finger Grip Pose. Its fields are the five curls (thumbCurl, indexCurl, middleCurl, ringCurl, littleCurl), thumbOpposition and spread. ToValues() and FromValues(...) convert to and from FingerPoseValues.

Hand and elbow IK for held items, including the holster animation. Runs at execution order 20, after head (10) and spine (15).

The holster timings are Inspector fields under Holster: holsterOffset, holsterTiltAngle, holsterDuration, drawDuration, drawStartWeight, leftHolsterOffset and twoHandedBlendDuration. They are described in Items.

PlayerSpineStabilizer#

Requires an Animator. Keeps the upper body steady while the head looks around. Runs at execution order 15. It is tuned through the spine fields of PlayerSettings.

Multiplayer add-on bridges#

Each optional add-on has one bridge per networking library. Both bridges expose the same item-state method and keep a list of networked world item prefabs.

ClassNamespacePublic API
FishNetPlayerBridgeFBSystem.FishNetNotifyLocalItemStateChanged(ItemEquipArgs). Serialized list: networkWorldItemPrefabs.
PurrNetPlayerBridgeFBSystem.PurrNetNotifyLocalItemStateChanged(ItemEquipArgs). Serialized list: networkWorldItemPrefabs.

The bridges are configured by their Setup Wizards. See Multiplayer (FishNet) and Multiplayer (PurrNet).

Demo classes#

These classes are demo code, not part of the core API. They are in the namespace Player.Demo.

  • PlayerEventLogger: implements both listener interfaces and logs every event. Use it as a template.
  • PlayerInventory: the owned item ids and starter items.
  • PlayerInteraction (E) and PlayerDropSystem (G): pickup and drop.
  • WorldItem: the dropped item. Its itemId must match the item in the container.
  • DemoGuidePanel (F1) and DemoGripToggle (H).
